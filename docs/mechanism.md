# Mechanism

Miners ship a specialised small model, a harness, a router and an escalation path as two Hugging Face repositories and commit the revision on chain with a fee and a declared hardware profile. The server mirrors the committed files by sha256. During the evaluation window each miner runs its own submission on its own GPU inside the pinned images, with no network except the recording gateway, a frozen clock, CPU, memory and process limits, read only mounts and every capability dropped. The gateway writes every model, tool and relay call into a transcript, which the miner signs and uploads before Freeze 2, when the receipts are sealed under a Merkle root. After the labels release, every validator replays every transcript on CPU: it answers each model call from the transcript, recomputes every tool response, checks every relay receipt and grades the answers. Validators do not run submissions on their own GPUs. The coordinator, run by the subnet owner, reruns a sample of each miner's model calls on a GPU of the miner's profile and requires an exact token match. A validator with a GPU of that profile can opt in and run the same check on the same calls with the same code. A miner with no spot check result scores zero in the specialist model pool and the system pool for that epoch. If no coordinator report arrives at all, validators keep the last settled weights and the server settles the epoch void. Miner emission goes to two pools: the specialist model pool takes 60% and the system pool 40%. The system pool scores the model, harness, router and escalation working together; the harness, router and escalation have no pools of their own. Scores are one sided lower bounds, a ladder keeps each miner's best per artifact, validators set weights themselves and the server publishes the consensus ledger.

Serving (mechanism 0.9.0) takes no share of miner emission. Operators are paid from billing: each card gets the arena's `revenue_share`, 80% of the metered billing for the requests it served, and Microtensor keeps 20%. Once a UTC day the gateway's signed receipts are folded per operator card, and validators check the receipts root and every signature before a settlement is used (`microtensor_subnet/serving/settle.py`, `receipts.py`, `audit.py`). Compute takes no share of miner emission either.

Code map: `microtensor_subnet/chain` (commitments, epochs, weights), `microtensor_subnet/core/items.py` (bundles), `microtensor_subnet/artifact` (manifest and checks), `microtensor_subnet/validator` (the epoch pipeline; `spotcheck.py` reads the coordinator's reports, and `rerun` holds the spot check code a validator with a GPU runs), `microtensor_subnet/scoring` (bounds, the two pools, SQL grading), `microtensor_subnet/cli/submit.py` and `microtensor_subnet/cli/epoch.py`.
